# 🌤️ Weather App

Ứng dụng xem dự báo thời tiết hiện tại của một thành phố và lưu trữ lịch sử tìm kiếm.

## 🔌 API Đã Sử Dụng
* **wttr.in API**: Sử dụng để lấy dữ liệu thời tiết thực tế dựa trên tên thành phố.
  * Endpoint: `https://wttr.in/{thanh_pho}?format=j1`

## 🚀 Cách Chạy Ứng Dụng
Vì đây là dự án sử dụng thuần Vanilla JavaScript (HTML/CSS/JS), bạn không cần cài đặt thêm thư viện (như Node.js hay npm). Có 2 cách để chạy:
1. **Cách 1 (Khuyên dùng):** Mở thư mục `weather_app` bằng VS Code, sau đó nhấp chuột phải vào file `index.html` và chọn **"Open with Live Server"** (Cần cài đặt extension Live Server trước).
2. **Cách 2:** Nhấp đúp chuột trực tiếp vào file `index.html` trong thư mục để mở thẳng trên trình duyệt (Chrome/Edge/Safari...).
