# 🖼️ Infinite Scroll Gallery

Thư viện ảnh hỗ trợ tải thêm ảnh tự động khi cuộn chuột (Infinite Scroll) và xem ảnh phóng to (Lightbox).

## 🔌 API Đã Sử Dụng
* **Lorem Picsum API**: Sử dụng để lấy danh sách hình ảnh ngẫu nhiên với chất lượng cao.
  * Endpoint (List ảnh): `https://picsum.photos/v2/list?page={page}&limit={limit}`
  * Endpoint (Lấy ảnh độ phân giải thấp/cao): `https://picsum.photos/id/{id}/{width}/{height}`

## 🚀 Cách Chạy Ứng Dụng
Dự án thuần HTML/CSS/JS không yêu cầu môi trường phức tạp.
1. **Cách 1 (Khuyên dùng):** Khởi chạy bằng extension **Live Server** trong VS Code thông qua file `index.html`.
2. **Cách 2:** Nhấp đúp chuột vào file `index.html` để mở thẳng bằng trình duyệt yêu thích của bạn.
