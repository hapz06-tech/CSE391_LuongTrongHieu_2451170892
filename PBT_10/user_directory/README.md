# 👥 User Directory (CRUD)

Ứng dụng quản lý danh bạ người dùng với đầy đủ các tính năng Thêm, Đọc, Sửa, Xóa (CRUD) và tìm kiếm real-time.

## 🔌 API Đã Sử Dụng
* **JSONPlaceholder API**: Cung cấp Fake REST API để thao tác với dữ liệu người dùng.
  * Endpoint (GET/POST/PUT/DELETE): `https://jsonplaceholder.typicode.com/users`

## 🚀 Cách Chạy Ứng Dụng
Vì đây là dự án sử dụng thuần Vanilla JavaScript (HTML/CSS/JS), bạn không cần biên dịch mã. Có 2 cách để chạy:
1. **Cách 1 (Khuyên dùng):** Mở thư mục `user_directory` bằng VS Code, nhấp chuột phải vào file `index.html` và chọn **"Open with Live Server"**.
2. **Cách 2:** Mở trực tiếp file `index.html` bằng trình duyệt web của bạn.
